### [1] [MV2: Multi-View Multi-Vehicle Driving Dataset for Novel View Synthesis](https://arxiv.org/abs/2608.12442)
*Sanjay Bhargav Dharavath,Hanvitha Saraswathi Mukkamala,Faizan Farooq Khan,Ioannis Kakogeorgiou,Aditya Arun,C V Jawahar,Zakaria Laskar*

Main category: cs.CV

TL;DR: 提出多视角多车辆驾驶数据集MV2，通过不同车辆（汽车、踏板车、无人机）的协同采集构建大规模真实场景新视角合成基准，填补了驾驶领域大视角外推评测的空白。

  <summary>Details</summary>
Motivation: 1. 现有驾驶NVS数据集仅含单轨迹序列，评测局限于视角插值，无法评估大幅视角变化下的外推能力。
2. 单车辆多视角采集在真实交通中不可行，导致缺乏真实动态场景的多视角 Driving NVS 数据。
3. 部分ynthetic数据或静态 masking 方案无法覆盖真实动态物体的多视角一致性。
4. 当前缺乏统一注册且经人工验证的 aerial-to-ground 驾驶多视角数据集。

Method: 1. 核心思路：利用三种不同平台（四轮车、两轮车、无人机）的同步但独立轨迹采集同一动态城市场景，构建跨车辆视角变化的NVS测试床。

### [3] [LocusGS: Spatially Grounded Tokens for Feed-Forward 3D Gaussian Splatting](https://arxiv.org/abs/2608.12825)
*Wenyu Li,Sidun Liu,Tongrui Hu,Peng Qiao,Yong Dou*

Main category: cs.CV

TL;DR: LocusGS 提出一种 spatially grounded token 机制，通过为 query-based feed-forward 3DGS 的每个 Gaussian query 显式附加 3D anchor（中心+支撑半径）并在解码器各层逐步精调，解决了纯 latent query 导致的空间相干性缺失问题，实现了更结构化的高斯分布与更高渲染质量。


<details>
  <summary>Details</summary>
Motivation: 1. 现有 query-based feed-forward 3DGS 方法将 query 表示为纯 latent 特征，缺乏显式空间定位，导致同一 query 解码出的高斯分散到场景远距离区域，空间相干性弱。
2. 现有方法中 query 与场景的空间责任归属不清晰，多视图特征聚合与高斯生成过程缺乏空间约束，无法保证 query 覆盖局部连贯区域。
3. 当前密集预测类方法（如 PixelSplat、MVSplat）的高斯预算与图像分辨率、输入视图数耦合，而 query-based 虽解耦预算但牺牲了空间组织性。

Method: 1. 核心思路：为每个 Gaussian query 显式建模 3D anchor 状态（中心+支撑半径），在解码器各层自回归精调，并将该锚点作为特征聚合、token 交互与高斯生成的统一空间参考系。
2. Anchor-to-ray 几何偏置：利用 patch-level Plücker rays 将 anchor 中心投影到图像平面，在 cross-attention 中引导 query 聚合 spatially relevant 的多视图特征，而非全局无差别聚合。
3. Anchor-centered 高斯解码：以精调后的 anchor 中心为局部参考原点，将高斯参数（中心、尺度、旋转）解码为相对于锚点的局部偏移与尺度，强制同一 query 的高斯分布于锚点邻域内。
4. 渐进式空间精调：anchor 状态随解码器层数从粗到细逐步更新，使 query 在早期建立粗略空间位置，后期精确定位，实现 query 与 3D 场景结构的对齐。

Result: LocusGS 在 novel view synthesis 基准上验证，在相同 Gaussian budget 下优于 query-based Gaussian token baseline（如 TokenGS、GlobalSplat）。实验表明其 learned anchors 形成连贯的空间布局，解码出的高斯呈现局部紧凑分组，散射现象显著减少，空间组织性更接近场景真实结构。

Conclusion: 1. 核心价值：显式 3D anchor 状态为 query-based feed-forward 3DGS 提供了 spatial grounding，在不增加 Gaussian 预算的前提下同时提升了渲染质量与空间结构性。
2. 关键局限：anchor 的精调质量依赖初始定位与多视图几何一致性，在弱纹理、重复结构或极稀疏视图场景中可能产生模糊或错误的空间责任划分；方法上限受限于 anchor 数量与场景复杂度的匹配程度。
3. 关键 takeaway：将隐式 latent query 替换为具有显式空间参数的 anchored query，是改善 3D 重建任务中结构化生成的有效范式，可推广至其他 set-prediction 场景（如 3D 物体检测、场景补全）。

Abstract: Recent query-based feed-forward 3DGS methods represent a scene using learnable queries, each aggregating multi-view evidence and decoding a group of Gaussians. Ideally, different queries should specialize in coherent local regions of the scene. However, we observe that Gaussians decoded from the same query often scatter across distant scene regions, resulting in weak query-level spatial coherence and poor alignment with the scene structure. We attribute this behavior to the purely latent representation of existing Gaussian queries. To address this limitation, we introduce LocusGS, which augments each Gaussian query with a 3D anchor state consisting of a center and a support radius. The anchor state is progressively refined across decoder layers and is used throughout query interaction, multi-view feature aggregation, and Gaussian generation. Specifically, an anchor-to-ray geometric bias guides each query toward spatially relevant image observations, while anchor-centered decoding organizes its Gaussians within a local region. Experiments on novel view synthesis benchmarks show that LocusGS improves rendering quality over query-based Gaussian token baselines under the same Gaussian budget. Further analysis shows that the learned anchors form coherent spatial layouts and lead to more structured Gaussian distributions, demonstrating that explicit anchor states improve the spatial organization. Our project page: https://leo-frank.github.io/LocusGS_viewer.
