### [1] [ViTacWorld: Scaling Visuo-Tactile World Models for Contact-Rich Robot Manipulation](https://arxiv.org/abs/2607.22530)
*Yunao Huang,Shiyu Sang,Haotao Lu,Suting Ni,Shijie Wu,Ziyang Guo,Ye Shi,Jingya Wang*

Main category: cs.RO

TL;DR: 首个面向接触丰富机器人操作的动作条件视触觉世界模型框架，同时支持视触觉动作轨迹生成与策略评估，解决视触觉数据难以大规模扩展的瓶颈。


<details>
  <summary>Details</summary>
Motivation: 1. 真实视触觉交互数据采集成本高、依赖专属硬件、任务/场景多样性有限，难以支撑大规模接触丰富操作学习。
2. 现有视触觉机器人策略仅关注触觉信号的消费或内嵌，缺乏可生成任务相关视触觉数据以训练下游策略的可扩展方案。
3. 现有触觉仿真数据受限于接触建模精度、资产真实度、任务多样性，且纯视觉动作条件世界模型无法捕捉接触丰富操作中的隐式接触状态。

Method: 1. 核心思路：将大动作条件机器人视频先验扩展为视触觉双流生成框架，通过多阶段训练实现时间对齐的视触觉动作轨迹生成，为下游策略提供数据支持与评估能力。
2. 视触觉流对齐架构：将触觉信号作为额外生成视角，通过视图感知条件注入与跨视图注意力机制实现视觉-触觉流的时间对齐与跨模态一致性。
3. 可扩展三阶段训练流程：先基于大规模公开与仿真视触觉轨迹预训练，再用真实世界策略回滚微调，降低目标任务适配成本，同时利用仿真数据补充预训练阶段的规模与多样性。
4. 双功能定位：区别于内嵌触觉预测的策略类工作，作为外部可复用数据生成器，同时支撑合成回滚生成与动作条件下的策略评估。

Result: 在插入、剥离、插拔等接触丰富操作任务上验证，生成的回滚具备物理合理性，可通过可扩展数据增强提升下游轻量模仿策略与VLA类触觉策略的性能，同时能支撑动作条件下的策略评估，真实场景实验验证了框架有效性。

Conclusion: 1. 核心价值：首个实现视触觉动作轨迹生成与策略评估的世界模型框架，突破了接触丰富操作中视触觉数据扩展的瓶颈。
2. 主要限制：合成数据的有效性依赖预训练数据的任务/场景覆盖度，且仿真触觉的保真度不足仍会限制生成回滚的物理真实性与策略迁移效果。
3. 关键takeaway：触觉信号直接锚定物理接触的特性，使其成为比纯视觉更易缩小仿真-现实gap的模态，适合用于扩展接触丰富操作的训练数据。

Abstract: Contact-rich robot manipulation requires physical interaction cues that are often invisible to cameras, making tactile sensing essential for robust control. However, scaling visuo-tactile robot learning remains difficult because real tactile interaction data are expensive to collect, hardware-dependent, and limited in task and scene diversity. We present ViTacWorld, an action-conditioned visuo-tactile world model for scalable contact-rich robot manipulation. ViTacWorld leverages public real tactile datasets and a constructed simulation environment to scale visuo-tactile-action data, exploiting the fact that tactile signals are directly grounded in physical contact and can exhibit a smaller simulation-to-real gap than purely visual observations. The model is first pretrained with large-scale real and simulated visuo-tactile trajectories, and then finetuned with real-world policy rollouts to better match downstream manipulation behaviors. Given robot actions, ViTacWorld predicts temporally aligned visual observations and tactile feedback, enabling visuo-tactile-action rollout generation. To the best of our knowledge, ViTacWorld is the first framework that uses a world model for robot visuo-tactile-action trajectory generation and policy evaluation. It serves two roles: synthesizing rollouts to improve downstream tactile policies, and evaluating policies by predicting action-conditioned visuo-tactile outcomes under controlled action sequences. Experiments on contact-rich manipulation tasks show that ViTacWorld generates physically meaningful rollouts, improves policy performance through scalable data augmentation, and enables action-conditioned policy evaluation. Project page: https://vitacworld.github.io/

### [2] [Ordered Action Tokens for Visuomotor Policy Learning](https://arxiv.org/abs/2607.21670)
*Chaoqi Liu,Yue Zhao,Haonan Chen,Xiaoshen Han,Jiawei Gao,Ehsan Adeli,Yilun Du*

Main category: cs.RO

TL;DR: OAT提出一种学习型动作标记器，首次同时满足高压缩、完全可解码和有序标记空间三个理想特性，为视觉运动策略提供兼具灵活性与性能的离散接口。


<details>
  <summary>Details</summary>
Motivation: 1. 现有分析方法（如逐维度分箱）产生的标记序列过长，随动作维度与预测时域增长呈线性膨胀，不适用于深度策略与延迟敏感场景。
2. 学习型潜层标记器虽能压缩，但缺乏顺序语义结构，任意策略采样可能无法解码为有效动作，且未显式建模粗到细控制信息。
3. 现有方法均未同时满足压缩率、可解码性和有序结构三项要求，限制了与自回归及流匹配等下游策略的兼容性。

Method: 1. OAT的核心思路是利用Transformer寄存器结合有限标量量化，通过前缀解码训练诱导粗到细的有序标记空间。
2. 采用带寄存器（register tokens）的Transformer编码时序动作块，经有限标量量化（FSQ）构建离散瓶颈，生成有序标记序列。
3. 引入嵌套前缀训练机制，强制每个标记前缀解码为有效动作块，使早期标记编码粗粒度控制信息，后续标记细化残差细节。
4. 提出块自回归解码调度框架，统一支持逐标记自回归、并行解码及2的幂次分组解码，将策略调用复杂度从线性降至对数。

Result: 在自回归策略生成动作标记与标记协同训练策略（以动作标记损失监督VLM，流匹配专家执行）两种主流范式下，基于三种策略骨干、超过60个任务、涵盖五个仿真基准与真实世界实验验证，OAT在保持强策略性能的同时，推理时支持从单标记到完整序列的灵活预算分配，实现保真度与计算成本的anytime权衡。

Conclusion: 1. OAT通过有序标记空间与完全可解码性，将动作标记化从离线压缩提升为策略友好的在线接口，核心价值在于粗到细结构同时服务于训练监督与推理灵活度。
2. 方法成立依赖标记顺序与下游策略预测顺序的显式对齐，若策略采用非因果或全局attention架构，有序性收益可能被削弱。
3. 标记协同训练中性能增益主要来自单标记前缀重构目标对VLM表示的全局约束，而非标记本身的信息容量上限，因此token长度受任务控制复杂度隐性约束。

Abstract: Action tokenization maps continuous robot action chunks to discrete tokens and has become an important interface for modern visuomotor policies. Existing approaches either rely on analytical discretization methods that produce prohibitively long token sequences or learned latent tokenizers that lack structure, limiting their compatibility with downstream policies. In this work, we identify three desiderata for action tokenization - high compression, total decodability, and an ordered token space - and introduce Ordered Action Tokenization (OAT), a learned action tokenizer that satisfies all three. OAT discretizes action chunks into an ordered sequence of tokens using a transformer with registers, finite scalar quantization, and ordering-inducing training mechanisms. By training each token prefix to decode into a valid action chunk, OAT places coarse control information in early tokens and uses later tokens to refine residual detail, yielding an anytime tradeoff between inference cost and action fidelity. We validate OAT in two prevailing uses of action tokens: autoregressive policies that generate tokens for control, and token co-training policies that use token losses to shape the vision-language model context consumed by a flow-based action expert. Across three policy backbones and more than 60 tasks spanning five simulation benchmarks and real-world settings, OAT consistently delivers strong policy performance while offering significantly greater flexibility at inference time.

### [3] [Robot-Factored World Models via Robot Rendering](https://arxiv.org/abs/2607.22535)
*Byungjun Kim,Taeksoo Kim,Hyunsoo Cha,Hanbyul Joo*

Main category: cs.RO

TL;DR: 本文提出机器人因子化世界模型接口，将机器人动作实现与场景响应预测解耦，通过标称轨迹和URDF渲染几何作为视觉条件，解决机器人操作视频世界模型的具身泛化与预测泄漏问题，是具身世界模型条件接口设计的代表性工作。


<details>
  <summary>Details</summary>
Motivation: 1. 现有机器人视频世界模型将具身控制信号直接作为条件，要求模型同时学习机器人动作实现（由本体、控制器决定）和场景响应两个独立过程，学习负担过重。
2. 基于已记录实现状态的视觉条件（如VAP）虽与未来视频视觉对齐，但已包含接触、柔顺、闭环修正等交互结果，泄漏了本应由世界模型预测的目标信息。
3. 现有方法依赖具身特定的控制向量表示，无法泛化到未见过的机器人本体或人类演示重定向的场景。

Method: 1. 核心思路：将机器人专属的动作实现过程前置到世界模型之外，以标称轨迹和URDF渲染的机器人几何作为统一视觉条件接口，使世界模型仅需学习场景对机器人运动的响应。
2. 提出部署可用的标称轨迹作为中间条件信号：将动作通过机器人自身控制器和运动学前滚生成接触发生前的标称轨迹，既避免模型学习具身专属的动作实现过程，又避免使用含未来交互结果的已实现状态导致的信息泄漏。
3. 设计跨本体跨视角的URDF渲染视觉条件：通过机器人URDF将标称轨迹渲染为相机对齐的机器人网格RGB与末端深度，将机器人几何、运动学、外观从世界模型中剥离，形成统一的模型输入接口。
4. 融合双流深度解决空间歧义：额外配对末端深度与场景深度，为接触、遮挡等空间关系提供超越图像平面重叠的几何线索，增强场景响应的预测准确性。
5. 接口天然支持人类演示重定向：可将人体手部运动重定向为对应机器人几何后直接作为条件，实现从人类演示到机器人操作视频生成的跨 motion source 泛化。

Result: 在机器人操作视频预测任务上，验证渲染接口相比向量条件基线的预测性能，证明其可泛化到未见过的机器人本体；进一步演示了通过重定向人体手部运动为机器人几何，可生成与人类演示对齐的机器人操作视频，覆盖多本体模拟场景与真实世界重定向生成的验证范围。

Conclusion: 1. 核心价值：机器人因子化接口成功将具身专属因素从世界模型中剥离，既降低了世界模型的学习负担，又避免了预测泄漏，同时实现了跨机器人本体的条件泛化与人类演示驱动的视频生成。
2. 主要限制：方法依赖机器人URDF的建模精度和标称轨迹的可靠性，若本体建模误差大或控制器性能差，会直接影响条件信号的有效性；且当前验证以桌面操作为主，对复杂多体接触、非结构化场景的适用性尚未充分验证。
3. 关键takeaway：对于具身世界模型，将具身专属的实现过程前置为显式预处理、以视觉几何而非控制向量作为条件接口，是解决泛化性与预测泄漏问题的有效范式。

Abstract: Action-conditioned video world models predict future observations from an initial observation and an action signal. In robotics, actions influence future observations through two distinct processes: they are first realized into robot motion by the robot body and controller, and the scene then responds through contact and object motion. Conditioning directly on action commands asks the world model to learn the realization process itself, while conditioning on logged future states leaks the interaction outcomes it is meant to predict. We propose robot-factored world models, which move two robot-specific factors outside the world model. First, action realization: each command is rolled through the robot's own controller and kinematics into a deployment-available nominal trajectory, a middle signal that avoids both action-realization learning and future-state leakage. Second, robot rendering: this nominal trajectory is rendered through the robot URDF, factoring the robot's geometry, kinematics, and appearance out of the model and into explicit rendered robot geometry. To resolve depth ambiguity, we pair end-effector depth with scene depth, giving geometric cues for contact and occlusion beyond image-plane overlap. Together, camera-aware static RGB/depth context and rendered robot geometry form a shared visual world-model interface that stays consistent across viewpoints and robot embodiments, so the model sees the action only as visible robot geometry and learns how objects respond to it. Our experiments show that the rendered interface outperforms vector-conditioned baselines and generalizes to unseen robot embodiments at inference. We further demonstrate that our model generates robot manipulation videos from human demonstrations by retargeting and rendering the hand motion as robot geometry.

### [4] [One Hand Watches The Other: Dynamic Multi-Agent Cooperation for Sample-Efficient Bimanual Manipulation in Dynamic Environments](https://arxiv.org/abs/2607.22119)
*Jan Ole von Hartz,Abhinav Valada,Joschka Boedecker*

Main category: cs.RO

TL;DR: 打破多流操纵策略对外生参考系的因果依赖，提出轻量级、与基础策略无关的 DynaMAC 框架，通过将动态对象（含对侧手臂）建模为动态任务参数，在保持产品专家融合样本效率的同时，统一解决动态环境、多机器人合作与双手协调问题，实现从静态演示的零样本动态泛化。


<details>
  <summary>Details</summary>
Motivation: 1. 现有多流策略假设参考系严格外生，在动态环境或多臂协调中，参考系成为机器人动作的内生函数，导致产品专家融合因果失效。
2. 现有双手协调方法或扩大动作空间降低样本效率（单策略），或采用固定领导-跟随架构引发推理延迟且角色无法动态转换。
3. 动态场景高质量演示数据稀缺且采集成本极高，现有方法未能利用静态演示泛化至动态非平稳环境。

Method: 1. 核心思路：DynaMAC 将对方手臂/环境对象视为动态任务参数，通过对多流策略输出进行运动学分析识别刚性耦合，在不修改基础策略的情况下恢复融合一致性。
2. 轻量级策略无关层设计，可直接叠加于 MiDiGaP 等现有多流策略之上，保留原生样本效率、推理速度与可解释性。
3. 基于策略流推理 kinematic links，动态筛选并加权融合相关参考系，替代固定外生任务参数。
4. 无需显式 leader 定义，实现协调角色隐式、动态切换，统一多智能体合作范式。

Result: 基于 RLBench 扩展构建 DynaBench 基准，在仿真与真实机器人硬件上评估动态抓取、双手协调与外部扰动任务。DynaMAC 在动态与双臂场景下显著优于概率与生成式基线，支持从纯静态演示零样本迁移至动态环境，并对外部扰动保持鲁棒性。

Conclusion: 1. 核心价值：首次以统一框架消除多流策略的动态因果缺陷，将样本效率优势拓展至真实非平稳操作场景。
2. 主要限制：方法有效性高度依赖运动学链接检测精度；当存在视觉噪声或非刚性交互（如柔性物体操作）时，动力学建模假设可能崩塌；零样本动态泛化的边界任务类型文中未充分说明。
3. 关键takeaway：轻量级包装层架构证明了以最小代价升级现有高样本效率策略以适应动态场景的可行性，为人机协作中的数据效率瓶颈提供了优雅解法。

Abstract: Multi-stream robot manipulation policies achieve unparalleled sample efficiency and generalization by modeling actions relative to environmental reference frames. However, existing approaches typically assume these frames to be strictly exogenous. This causal assumption collapses in dynamic settings, such as when a single robot arm manipulates a moving object or when two arms coordinate, where each arm effectively becomes part of the dynamic environment of the other. We propose DynaMAC, a lightweight, policy-agnostic framework that resolves this causal limitation while preserving the sample efficiency, computational speed, and flexibility of multi-stream policies, DynaMAC treats the opposite arm as a dynamic task parameter, thereby providing a unified formulation for dynamic manipulation and bimanual coordination without requiring an explicit leader-follower relationship. To rigorously evaluate these capabilities, we introduce DynaBench, a novel benchmark for robot manipulation in dynamic environments. Across both dynamic environments and bimanual manipulation tasks, DynaMAC outperforms leading probabilistic and generative baselines by over 35 percentage points while requiring 20 times fewer samples. Crucially, DynaMAC generalizes zero-shot from static demonstrations to dynamic environments, substantially simplifying data collection and establishing an elegant bridge toward human-robot collaboration.
