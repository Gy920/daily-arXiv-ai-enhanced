### [1] [MV2: Multi-View Multi-Vehicle Driving Dataset for Novel View Synthesis](https://arxiv.org/abs/2608.12442)

Main category: cs.CV

TL;DR: 本文提出MV2多视角多车辆驾驶数据集与基准，填补了真实动态城市场景下大视点 Novel View Synthesis (NVS) 评测的空白，通过车载、滑板车与无人机多平台异源轨迹同步采集与严格配准，建立首个以跨平台推理为核心的驾驶NVS压力测试平台。


<details>
  <summary>Details</summary>
Motivation: 1. 现有驾驶NVS数据集均为单轨迹采集，仅能评测相邻帧插值，无法评估真实大视点外推能力。
2. 多视角动态驾驶场景难以通过单车辆重复通行采集，现有工作依赖合成数据或静态掩码，缺乏真实跨平台异源轨迹数据。
3. 当前跨视角评测常以FID等感知指标替代几何一致性度量，且缺乏相机姿态基准验证。
4. 前馈式姿态估计器在驾驶大视点场景下的表现未被 systematically benchmarked。

Method: 1. 核心思路：利用车、滑板车、无人机三种平台在真实交通中独立但同步行驶的轨迹，采集同一动态城市场景的多视角图像，构建跨平台训练-测试协议，迫使NVS与姿态估计方法在极大基线变化条件下进行外推式推理。
2. 通过SfM对全部序列做统一坐标系配准，并辅以人工逐像素对应点标注进行相机位姿校验，确保几何精度。
3. 设计两种评测范式：地-空跨视角NVS（空地之间）与跨路面平台NVS（车-滑板车之间），将训练与测试分别置于不同平台，强制大视点外推。
4. 在统一基准上系统比较了优化型与前馈型NVS方法、以及前馈与优化型姿态估计方法，揭示大视点下的性能衰减规律。

<details>
  <summary>Details</summary>

Method: 1. 核心思路：为每个 Gaussian query 附加显式 3D anchor state（中心+支持半径），并在 Transformer 解码器的各层中渐进式精炼，用于引导跨注意力、 query 交互与高斯解码。
2. 关键技术动作：提出 anchor-to-ray 几何偏置，将 query 导向空间上相关的图像观测；以 anchor 为中心的高斯解码，将原语组织在局部区域内。
3. 相比 TokenGS/GlobalSplat 等仅用潜空间特征的方法，LocusGS 首次将 3D 显式空间状态引入 query-based 前馈 3DGS，在相同高斯预算下实现更结构化的场景表示。

2. 主要限制：方法依赖正确的 anchor 初始化与渐进式精炼，其有效性受相机姿态精度与多视图几何约束质量的影响；在高度动态或纹理缺失区域，anchor 收敛稳定性可能受限。
3. 关键 takeaway：在基于 Transformer 的场景解码框架中，将隐式 token 与显式几何状态（中心+半径）耦合，是提升 query 空间 specialization 与整体重建结构的有效范式。

Ideally, different queries should specialize in coherent local regions of the scene. Our project page: https://leo-frank.github.io/LocusGS_viewer.
