### [3] [LocusGS: Spatially Grounded Tokens for Feed-Forward 3D Gaussian Splatting](https://arxiv.org/abs/2608.12825)
*Wenyu Li,Sidun Liu,Tongrui Hu,Peng Qiao,Yong Dou*

Main category: cs.CV

TL;DR: LocusGS 是 query-based feed-forward 3D Gaussian Splatting 方法，通过显式 3D anchor state（中心+支撑半径）逐步细化并贯穿解码全过程，解决现有纯潜变量 query 导致高斯散射、空间相干性差的问题，在新视角合成任务中提升渲染质量并使高斯分布更具结构化空间组织。


<details>
  <summary>Details</summary>
Motivation: 1. 现有 query-based feed-forward 3DGS 方法将 query 表示为纯潜变量，缺乏显式空间语义，导致同一 query 解码的高斯分布散落在场景远处，query 级空间相干性弱。
2. 这种空间散射使得 query 无法与场景结构对齐，聚合的多视角证据与解码出的高斯均不受局部区域约束，影响重建的结构化程度。
3. 现有方法隐式定义 query 的空间职责，无法在特征聚合与高斯生成阶段直接引入空间先验约束。

Method: 1. 核心思路：为每个 Gaussian query 引入显式 3D anchor state（中心点 + 支撑半径），在解码器各层逐步细化，并引导 cross-attention、token 交互与高斯生成。
2. anchor-to-ray 几何偏置：利用 Plücker rays 将 anchor 中心与图像观测关联，引导 query 聚焦于空间相关的多视角区域。
3. anchor-centered 高斯解码：以细化后的 anchor 中心为参考点，将高斯解码为局部偏移，确保同一 query 的高斯聚类于紧凑局部区域。
4. 对比于仅用潜变量 query 的 TokenGS/GlobalSplat 等方法，LocusGS 在 query 表示中显式编码 3D 空间状态，使 query 的空间职责从隐式变为显式约束。

Result: 在 novel view synthesis 的多个 benchmark 上，LocusGS 在相同 Gaussian budget 下优于 query-based Gaussian token 基线。分析表明，学习到的 anchor 形成连贯空间排布，预测的高斯更少散射、更紧凑，空间组织性显著增强。

Conclusion: 1. 显式 3D anchor state（中心+半径）是提升 query-based feed-forward 3DGS 空间相干性与重建质量的关键，其价值不仅在于精度增益，更在于赋予 query 清晰的空间职责与结构化组织能力。
2. 该方法依赖 anchor 初始化的合理性及逐步细化机制，若场景复杂度极高或输入视角不足，anchor 可能收敛到次优位置或覆盖区域重叠/遗漏。
3. LocusGS 证明了在生成式 3D 重建中，显式几何状态的注入能替代部分隐式学习负担，为后续结合更强几何先验或动态场景扩展提供了统一框架。

Abstract: Recent query-based feed-forward 3DGS methods represent a scene using learnable queries, each aggregating multi-view evidence and decoding a group of Gaussians. Ideally, different queries should specialize in coherent local regions of the scene. However, we observe that Gaussians decoded from the same query often scatter across distant scene regions, resulting in weak query-level spatial coherence and poor alignment with the scene structure. We attribute this behavior to the purely latent representation of existing Gaussian queries. To address this limitation, we introduce LocusGS, which augments each Gaussian query with a 3D anchor state consisting of a center and a support radius. The anchor state is progressively refined across decoder layers and is used throughout query interaction, multi-view feature aggregation, and Gaussian generation. Specifically, an anchor-to-ray geometric bias guides each query toward spatially relevant image observations, while anchor-centered decoding organizes its Gaussians within a local region. Experiments on novel view synthesis benchmarks show that LocusGS improves rendering quality over query-based Gaussian token baselines under the same Gaussian budget. Further analysis shows that the learned anchors form coherent spatial layouts and lead to more structured Gaussian distributions, demonstrating that explicit anchor states improve the spatial organization. Our project page: https://leo-frank.github.io/LocusGS_viewer.
