### [1] [CDSeg: A Renderable Gaussian Carrier for Image-to-3D Label Transfer](https://arxiv.org/abs/2608.05482)
*Wentao Sun,Yiping Chen,Zhengsen Xu,Jonathan Li,John S. Zelek*

Main category: cs.CV

TL;DR: CDSeg 是无任务特定3D训练的通用2D-3D标签转移接口，以可渲染的3D高斯泼溅基元为载体，通过渲染自带的遮挡感知像素-基元关联，实现多视图2D掩码到持久化3D标签的融合，同时兼容点云与原生高斯两种场景的标注需求。


<details>
  <summary>Details</summary>
Motivation: 1. 现有2D分割模型仅输出视图级掩码，无法自主确定标签在3D空间中的持久化位置；
2. 任务特定的3D分割网络需大量3D标注训练，成本高且泛化性差；
3. 现有基于高斯的标签转移方法多需额外特征蒸馏或学习流程，且仅支持高斯场景，无法兼容原始点云标注需求；
4. 传统多视图投影投票仅能输出固定点集的标签，无法适配高斯原生渲染的场景查询需求。

Method: 1. 核心思路：以高斯泼溅的渲染过程为媒介，将2D掩码通过像素-基元关联写入3D高斯基元，经多视图融合后输出为持久化3D标签，无需任务特定3D训练。
2. 设计双模式载体：模式I将输入点一对一补全为高斯并保留原始索引，适配固定点集标注；模式II直接复用优化后的原生高斯基元，适配高斯场景标注，统一覆盖两类主流3D表示；
3. 复用渲染过程自动记录的遮挡感知像素-基元关联，无需额外学习3D对应网络即可完成标签到基元的分配；
4. 采用多视图majority投票结合k近邻滤波的融合流程，固化3D标签，同时支持输出到点云、原生高斯场景或任意目标视图。

Result: 在可提示分割、自动实例分割、语义分割、RGB到LiDAR转移四类任务上验证，覆盖DesktopObjects-360、NeRDS-360、ScanNet-v2三个Benchmark，涵盖桌面、室内、室外、驾驶多类真实场景，同时完成百万级基元的规模测试，两种载体模式均取得领先的标注精度。

Conclusion: 1. 核心价值：提供通用轻量的2D到3D标签转移方案，无需任务特定3D分割网络训练，即可同时支持点云与高斯场景的标注输出；
2. 主要限制：方法依赖校准多视图输入与高精度2D掩码源，模式II依赖预重建的高斯场景，无内置掩码误差校正机制，标签质量受上游2D模型性能直接制约；
3. 关键takeaway：高斯泼溅的渲染过程天然具备遮挡感知的像素-基元关联能力，可作为跨域3D标注的通用载体，无需额外学习3D对应关系即可高效完成视图级掩码的3D固化。

Abstract: Modern image models provide strong cues about \emph{what} should be segmented in each view, but their masks do not by themselves determine \emph{where} those labels should persist in 3D. We present Cross-Domain Segmentation via Gaussian Splatting (CDSeg), a label-transfer interface that requires no task-specific 3D segmentation training and uses Gaussian primitives as a renderable label carrier. An external mask source supplies the labels, while renderer-derived visibility determines which 3D primitives receive them. The carrier is instantiated either by completing each input point into one Gaussian, preserving its index, or by reusing the native primitives of an optimized Gaussian scene. CDSeg records pixel--primitive associations during rendering and fuses multi-view masks through voting and a local filter. The resulting labels can be returned to the original points, retained on the native Gaussian scene, or rendered into other views. CDSeg covers promptable, automatic instance, semantic, and LiDAR settings and processes scenes with millions of primitives in seconds. It obtains 92.35\% mIoU on DesktopObjects-360, 95.89\% on NeRDS-360, and 65.77\% on the full ScanNet-v2 validation split using the provided 2D semantic annotations. CDSeg thereby provides one interface for reusing 2D masks across point clouds, Gaussian scenes, and image views without a task-specific 3D segmentation network.

### [2] [Uncertainty-Aware World Model for Aerial Image-Goal Navigation](https://arxiv.org/abs/2608.05597)
*Deyi Zhu,Haoyu Fan,Yinan Zhu,Weichen Zhang,Shilin Ma,Xinlei Chen,Yansong Tang*

Main category: cs.CV

TL;DR: 本文针对大规模室外航空图像目标导航场景，提出不确定性感知的导航世界模型UA-NWM，将轨迹打分建模为条件分布外（OOD）检测问题，通过不确定性子空间建模多可能未来，解决传统世界模型点预测鲁棒性不足的问题，在效率与性能间取得平衡。


<details>
  <summary>Details</summary>
Motivation: 1. 现有基于世界模型的导航方法多采用单点或少量点预测进行轨迹打分，无法有效建模大规模室外场景下的多可能未来分布。
2. 确定性世界模型将多可能未来坍缩为单一平滑预测，易偏离真实状态分布的高密度区域，导致轨迹打分可靠性差。
3. 随机世界模型虽能捕捉多可能未来，但需大量采样近似分布，计算开销大，少量采样又会受随机性干扰导致打分不稳定。

Method: 1. 核心思路：将航空图像目标导航的候选轨迹打分建模为条件OOD检测问题，用不确定性子空间近似轨迹对应的未来状态条件分布，仅用未被不确定性解释的残差项打分，无需多轮采样即可实现鲁棒筛选。
2. 提出分层误差投影（HEP）模块，将预测表征与目标表征的差异分解为平行于不确定性子空间的可解释分量和正交的未解释残差分量，仅后者参与轨迹打分，避免对合理未来波动进行错误惩罚。
3. 采用轻量确定性骨干在DINOv3隐空间完成未来表征预测，相比随机世界模型大幅降低推理开销，同时保证表征质量。

Result: 在航空图像目标导航的离线和在线仿真基准上均持续优于现有导航世界模型，同时保持低推理延迟；真实无人机实验进一步验证了方法在实际场景中的部署可行性。

Conclusion: 1. 核心价值在于跳出传统世界模型“点预测打分”或“多采样近似分布”的范式，通过显式建模未来状态的不确定性结构，同时实现轨迹打分的鲁棒性与推理效率。
2. 深层限制是该方法强依赖DINOv3隐空间的流形假设，若未来状态偏离该低维流形分布，不确定性子空间的建模效果会显著下降。
3. 关键takeaway：导航场景下的轨迹打分无需依赖多采样或单一预测，显式利用未来状态的不确定性信息即可更准确地区分合理候选轨迹与错误轨迹。

Abstract: Aerial image-goal navigation requires an unmanned aerial vehicle (UAV) to reach a target location specified by a goal image. Existing world-model-based methods rank candidate trajectories using predicted futures, but typically rely on only one or a few point predictions, which is inadequate for large-scale outdoor environments with substantial future-state uncertainty. To address this limitation, we propose the Uncertainty-Aware Navigation World Model (UA-NWM), an efficient latent world model for aerial image-goal navigation, which formulates trajectory scoring as conditional out-of-distribution detection. UA-NWM represents plausible futures with an uncertainty subspace and decomposes the prediction--goal discrepancy into uncertainty-explainable and unexplainable components. Only the unexplainable residual is used for scoring, enabling robust selection without multiple future samples. Extensive experiments demonstrate that UA-NWM consistently outperforms existing navigation world models while maintaining low inference latency. Real-world UAV experiments further validate its practical applicability. Project page: https://duryi.github.io/UA-NWM-Project-Page

  <summary>Details</summary>

Abstract: Humanoid household tasks often require concurrent loco-manipulation, where the robot must move, adjust posture, maintain balance, and manipulate objects as a single coordinated behavior. Yet existing humanoid policies typically decompose locomotion and manipulation, while recent world-action models remain either arm-centric or video-centered. We present $ω$-0, a latent predictive whole-body world-action model for real-world humanoid concurrent loco-manipulation. Given a language instruction, current visual observation, and robot proprioceptive state, $ω$-0 directly predicts controller-compatible whole-body action latents for real-robot execution. Rather than reconstructing future videos, $ω$-0 learns compact future observation embeddings as a lightweight predictive objective, coupling latent visual foresight with diffusion-based whole-body action generation. The model supports egocentric RGB, exocentric RGB, and exocentric depth inputs, and leverages controller-based simulation replay to ground human/public visual-motion priors into robot-executable action latents. We further collect $ω$-HOME, a 40+ hour real-world household humanoid dataset with synchronized multi-view observations, whole-body SMPL motions, robot states, and action latents. Real-world experiments on 11 household tasks demonstrate that a single $ω$-0 model can produce smooth manipulate-while-moving behaviors and consistently outperform representative imitation learning, VLA, humanoid, and WAM baselines.
